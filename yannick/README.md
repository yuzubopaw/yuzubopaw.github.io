# Yannick's Skill Play

Web mini-games for **WONG Yannick Yik Yin**, mapped to the Watchdog OPRS discharge report (June 2026). English / 繁體中文. Built for an iPad or laptop with a grown-up sitting beside him.

These are **home practice tools**, not a replacement for school, playdates, or therapy.

**Play online:** https://yuzubopaw.github.io/yannick-skill-games/

## Open the games locally

Double-click `index.html`, or from this folder:

```bash
python3 -m http.server 8765
```

Then open [http://localhost:8765](http://localhost:8765).

On iPad: open the page in Safari → Share → Add to Home Screen.

**How a 5-year-old plays:** almost no reading. Pictures to tap, a blue speaker to hear the question again. A grown-up sits beside him. The 👤 button is the grown-up guide (that page still has words).

## Games and the report

| Game | Skill in the report |
|---|---|
| Wait, Then Share | Turn-taking, wait, listen first, recall rules |
| My Space Bubble | Personal space; wave/high-five at school; hugs at home |
| Feeling Finder | Complex emotions: worried, nervous, embarrassed, frustrated |
| Mind Reader | Theory of mind / mind reading |
| Kind Choices | Conflict resolution; words instead of pinching |
| Many Ideas | Flexible thinking; varied ideas, not the same drawing |
| School Ready | Primary-school situations (carpet, line, recess, asking) |
| Follow the Steps | 3–4 step tasks; remember the order |
| Sound Superstar | AEPS H: rhyme, first sound, blending (beginner) |
| Super Sentences | Grammar recast (*bought* not *buyed*), because/if, precise verbs and parts |
| Start at the Top | Handwriting Without Tears; start at the top; left-hand friendly |
| Guess What | Describing / guessing vocabulary |
| Body Break | OT movement breaks: frog jumps, wall push, bear walk, Superman |

Stars are saved in the browser. After every two table games, the app suggests a body break.

## Grown-up tips (from the report)

- Praise waiting and new ideas, not only correct answers.
- Recast grammar: “Oh! Yesterday you **bought** a toy.”
- Left-handed: keep the right side of the table clear; start letters at the top star.
- Keep using real playdates, swimming, playgrounds, buttons, bottles, and pencil work.
